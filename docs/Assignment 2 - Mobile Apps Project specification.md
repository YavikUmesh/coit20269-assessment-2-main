## Objectives

This assessment item relates to the unit learning outcomes 2, 3, 4 and 5 as stated in the unit profile. The overall objective of this assignment is to specify, design, implement, and test a mobile hybrid app.

### Overview

This assignment involves a group project. A group will consist of three (3) students unless otherwise approved by the tutor or unit coordinator. This assignment requires you to generate a semi-original idea for mobile hybrid app. Conduct research on app market trends, market gaps, customer demands, monetisation potential, competition, future growths to generate a suitable idea. You will then need to identify the high-level user requirements and user stories to design the app. Finally, you will need to develop a three-tier mobile hybrid app as per the specification outlined in the next section.

Task Description

The tasks that need to be accomplished for this assignment are:

## Part A: Project (25 marks)

You will develop a mobile hybrid app to accomplish the high-level user requirements or user stories that you have come up with. The app should have three parts – front-end (client), back-end (server) and database. The completed application should be deployable and fully functional on a smart device (e.g., Android smartphone).

The mobile hybrid app should be developed using the same platforms and tools as used in Assignment 1 - Full Stack Hybrid App. The general skills and approaches used and assessment criteria followed in the previous assignment are expected to be utilised in this project. However, you are expected to use additional Cordova plug-ins and Node.js packages, as necessary.

The deliverables for this part are:

- Database – Create and maintain a MongoDB document database using the Atlas cloud service for online storage of mobile app data.

- Client – Develop, test, and maintain a mobile web client app using an integrated suite of mobile software development tools. More specifically you need to use jQuery, jQuery Mobile, JavaScript, HTML5, and CSS.

- Server – Develop, test, and maintain an Express web server app and API using JavaScript and Node.js with various Node.js packages.

The Express web server must establish all connections over HTTPS. The server code must not contain any hard-coded credentials. It should incorporate appropriate middleware to enable Cross-Origin Resource Sharing (CORS) and to authenticate incoming requests. Additionally, related endpoints should be organised using Express Routers, splitting them into separate files to improve code maintainability.

- Hybrid App – Deploy the mobile web client app as a Hybrid App to smart devices (e.g., Android smartphone) using the Cordova platform.

- Server Deployment – Deploy the Express web server app using an online service (e.g., Render).

- Version Control – Your code (for both the front-end and back-end) shall be maintained in a GitHub repository, with a complete history of all changes recorded through version control.

- Functional Requirements – The mobile hybrid app must incorporate login, logout, and sign-up functionalities. It should incorporate user interactions involving at least three different types of HTTP requests selected from GET, POST, PUT, and DELETE.

## Part B: Presentation (15 marks)

You will deliver a small presentation during the Week 12 tutorial class to illustrate your mobile hybrid app that you have developed for Part A. The deliverables for this part are:

- Live demonstration of your mobile hybrid app in a smart device/emulator/browser

- Presentation of the following using PowerPoint slides:

- Motivation for producing the app – Who will use the mobile app and why they will use it (target audience). This would require research – similar apps – market gaps – meet new trends etc.

- High-level user requirements – Written from the perspective of user needs

- Software architecture – Clearly depict all components

- Test results (preliminary) – Provide screenshots of the results found from testing your app

- Vulnerability analysis results (preliminary) – Steps for performing vulnerability analysis are explained in the Week 11 tutorial handout. You are not required to fix the vulnerabilities; you simply need to identify and report the vulnerabilities.

## Expectations

Some important vectors in evaluating your hybrid mobile app include:

- Functionality – Does it meet the user requirements?

- Utility – Does it deliver the user what is expected?

- Usability – Is it comfortable/easy/intuitive to use?

- Aesthetic – Is it attractive?

You will need to work on this assignment in parallel with other assessments. What is expected is that, to meet the assignment requirements, you will need extra functionalities. This will be supported mainly by:

- Cordova plug-ins

- Node.js packages

- Your own code
